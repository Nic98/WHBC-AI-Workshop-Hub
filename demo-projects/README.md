# AI Workshop Hub Demo Projects

These three projects are platform demonstrations created for AI Workshop Hub.
They are intentionally credited to **AI Workshop Hub Demo**, not to fictional
students. Each project is a self-contained HTML file with no external network
dependency.

## Projects

1. **Eco City Simulator** — featured sustainability scenario explorer.
2. **Story Seed Lab** — interactive creative-writing prompt generator.
3. **Sound Shape Studio** — generative visual and sound-pattern playground.

The demos are suitable as temporary launch content. Replace them with approved
student work as projects become available.
